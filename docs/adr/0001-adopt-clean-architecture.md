# ADR-0001: Adopt Clean Architecture

- Status: Accepted
- Date: 2026-07-26
- Supersedes: None
- Superseded by: None

## Context

PROJECT SARATHI requires stable boundaries as its domain and integrations grow.

## Decision

Use inward-facing Clean Architecture boundaries for domain, application, interfaces, and infrastructure.

## Consequences

Domain logic remains independently testable, with additional structural discipline and explicit adapters.

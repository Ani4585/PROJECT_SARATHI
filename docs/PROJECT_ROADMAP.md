# PROJECT SARATHI Official Roadmap

The authoritative programme is the 10-phase, 60-milestone master roadmap in
[`project_sarathi_master_roadmap.html`](project_sarathi_master_roadmap.html).
It targets PROJECT SARATHI v1.0.0 at M60.

## Programme Phases

| Phase | Scope | Milestones |
|-------|-------|------------|
| 1 | Foundation and Core Runtime | M1-M11.5 |
| 2 | Developer Experience and Observability | M12-M18 |
| 3 | Extensibility and Plugin Architecture | M19-M24 |
| 4 | Data, Configuration and Persistence | M25-M30 |
| 5 | Web and API Foundation | M31-M36 |
| 6 | Concurrency, Tasks and Messaging | M37-M42 |
| 7 | Security and Governance | M43-M48 |
| 8 | Testing and Quality Engineering | M49-M53 |
| 9 | Packaging, Distribution and Delivery | M54-M57 |
| 10 | Ecosystem, Documentation and v1.0 | M58-M60 |

## Version Policy

Version `1.0.0` is reserved for official M60. The previously published
`v1.0.0-platform-kernel` tag is retained as an immutable experimental snapshot
and does not indicate official roadmap completion.

# PROJECT SARATHI Roadmap

This roadmap defines the framework path from the completed repository-audit
release to the first integrated platform kernel. Each milestone is a focused,
independently tested release that preserves the public APIs delivered earlier.

| Milestone | Version | Capability | Exit condition |
|-----------|---------|------------|----------------|
| M12.3 | 0.7.2 | Repository Audit Engine | Complete and tagged |
| M13 | 0.8.0 | Layered Configuration Engine | Complete |
| M14 | 0.9.0 | Domain Event System | Complete |
| M15 | 0.10.0 | Application Messaging | Complete |
| M16 | 0.11.0 | Module Runtime | Complete |
| M17 | 0.12.0 | Persistence Ports | Complete |
| M18 | 0.13.0 | Background Job Engine | Complete |
| M19 | 0.14.0 | Metrics Engine | Complete |
| M20 | 1.0.0 | Platform Kernel | Complete |

## Release Discipline

Every milestone requires focused tests, the complete regression suite,
compilation, the repository audit, documentation, a clean Git diff, a milestone
commit, and an annotated version tag.
